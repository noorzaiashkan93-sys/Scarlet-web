# Scarlet Web App

A small, installable web-app workspace for organising Roblox project notes and writing Lua drafts.

## Publish from an iPad
1. Sign in to GitHub in Safari and create a **public** repository named `scarlet-web`.
2. Extract the ZIP in the iPad Files app. Upload all files inside the extracted folder to the repository root (make sure `index.html` is at the root, not inside another folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Wait for GitHub Pages to publish. Your site address will be shown in the Pages section.

## Add it to the iPad Home Screen
Open the published HTTPS address in Safari, tap Share → Add to Home Screen, enable **Open as Web App** if shown, then tap Add.

## Notes
- Drafts and projects are stored in the browser on this device. Use Export Backup regularly.
- This app does not execute Lua or connect to Roblox servers.
- It does not control or modify games made by other people.
